## Prerequisites

- Node.js >= 24
- A Discord bot token with the required intents and permissions

## Install from npm

The package is published on npm and can be installed directly with `npx`:

```bash
npx -y @guildforge/mcp
```

This downloads and runs the latest published version. You only need to provide your environment variables.

### Configuration

Create a `.env` file or set environment variables:

```bash
DISCORD_TOKEN=your_bot_token
GUILD_ID=your_guild_id
```

## MCP Client Configuration

GuildForge works with any MCP-compatible client. Find your client below and follow the example.

### opencode

Add to your `opencode.jsonc`:

```jsonc
{
    "$schema": "https://opencode.ai/config.json",
    "mcp": {
        "guildforge": {
            "type": "local",
            "command": ["npx", "-y", "@guildforge/mcp"],
            "environment": {
                "DISCORD_TOKEN": "your_bot_token",
                "GUILD_ID": "your_guild_id"
            }
        }
    }
}
```

### Cursor

Add to your `.cursor/mcp.json` (create the file if it doesn't exist):

```json
{
    "mcpServers": {
        "guildforge": {
            "command": "npx",
            "args": ["-y", "@guildforge/mcp"],
            "env": {
                "DISCORD_TOKEN": "your_bot_token",
                "GUILD_ID": "your_guild_id"
            }
        }
    }
}
```

```json

    "mcpServers": {
        "guildforge": {
            "command": "npx",

            "env": {
                "DISCORD_TOKEN": "your_bot_token",

```

## Local development

If you want to contribute or run the server from source:

### Install dependencies

```bash
git clone https://github.com/guildforge/guildforge.git
cd guildforge
pnpm install
```

### Build

```bash
pnpm turbo build
```

The compiled output is available at `packages/mcp/dist/index.mjs`.

### Run

```bash
node packages/mcp/dist/index.mjs
```

For interactive inspection during development:

```bash
pnpm inspect
```

This builds the project and launches the MCP Inspector.
